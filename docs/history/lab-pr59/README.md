# Historical PowerCoder requirements and evidence

These are the original documents from nem-poweragent-lab PR 59 at
`e11038d54fbf6507a31eaf316a26d1817c8f3d71`. They preserve mission requirements,
decisions, failure investigations, evaluation observations, licensing caveats and
open backlog items during the move to Wattson. `SOURCES.json` records exact hashes.

They are historical inputs, not current installation instructions or claims about
this branch. Paths, model names, counts and interpreter assumptions describe their
original runs. The old AGENTS file is stored as text to prevent archived guidance
from becoming active instructions. Current validation and blockers are recorded
in `docs/POWERCODER_PORT_HANDOFF_2026-11-05.md`.

The original full implementation/history also remains on the lab repository's
`archive/pr59-before-wattson-20261105` branch. The cleaned lab PR retains its
independent work instead of deleting it alongside the model implementation.
