# Diagrams

These are the project's procedures drawn as **state charts**. Each arrow is a transition labelled with the command that causes it and the
observation that proves it worked (`cmd: ... | pass: ...`), so a chart is both documentation and a checklist. They are D2 text in git;
the pictures (`.svg`) are rendered from them.

| Chart | Procedure |
|---|---|
| [pod-lifecycle](pod-lifecycle.svg) | start, verify, use and stop the model pod |
| [gateway-lifecycle](gateway-lifecycle.svg) | the local model gateway: up, serving, backend failure, down |
| [model-load](model-load.svg) | the memory gate before any model is loaded or downloaded |
| [kit-lifecycle](kit-lifecycle.svg) | install `kit`, check a directory, pack, publish, size before download |
| [delivery-flow](delivery-flow.svg) | backlog issue to merged change, and local equals remote |
| [recipes](recipes.svg) | every `just` recipe and what it depends on (generated, never hand-edited) |
| [ecosystem](ecosystem.svg) | the picture in the README |

## They cannot drift from the code
- `just diagrams-check` fails if a chart names a `just` command that does not exist, if a transition in a procedural chart lacks a
  command or a pass observation, or if `recipes.d2` no longer matches the justfile. The same recipe-name check runs in CI
  (`tests/test_diagrams_in_sync.py`), so a PR that renames a recipe without updating its chart does not go green.
- `recipes.d2` is generated by `scripts/justfile_diagram.py`; `just diagrams` rewrites it and re-renders every chart.

## Changing a chart
Edit the `.d2`, keep `# procedural-chart` on its first line, give every transition `cmd: ... | pass: ...`, then:
```bash
just diagrams-check                                   # offline, no server needed
WATTSON_KROKI_URL=http://HOST:8010 just diagrams      # re-render the SVGs
```
Rendering needs a Kroki server. [kr0ki](https://github.com/promptexecution/kr0ki), our sibling project, runs one (x86_64 only for now:
kr0ki#150; on arm64 point `WATTSON_KROKI_URL` at an x86_64 machine). Use `.d2` or `.dot` sources: Mermaid needs a Kroki companion that kr0ki
does not run. The diagram text is sent only to the server you name.
